# Моя шпаргалка по Git

## 🔥 ОСНОВНЫЕ КОМАНДЫ

### 📦 Инициализация и клонирование
```bash
git init                        # создать репозиторий в текущей папке
git clone <url>                 # склонировать удаленный репозиторий
git clone <url> <папка>         # склонировать в конкретную папку

Работа с изменениями
git status                      # проверить состояние (какие файлы изменены)
git add <файл>                  # добавить конкретный файл в staging
git add .                       # добавить все измененные файлы
git commit -m "сообщение"       # создать коммит с сообщением
git commit -am "сообщение"      # add + commit для отслеживаемых файлов

Ветки (самое важное!)
git branch                      # посмотреть все ветки (* - текущая)
git branch <имя>                # создать новую ветку
git checkout <имя>              # переключиться на ветку
git checkout -b <имя>           # создать ветку и сразу переключиться
git merge <ветка>               # влить ветку в текущую
git branch -d <ветка>           # удалить ветку (после слияния)
git branch -D <ветка>           # принудительно удалить ветку

Работа с удаленным репозиторием
git remote -v                   # посмотреть удаленные репозитории
git push origin <ветка>         # отправить изменения на GitHub
git pull origin <ветка>         # скачать изменения с GitHub
git fetch origin                # скачать изменения без слияния

Просмотр истории
git log                         # полная история коммитов
git log --oneline              # сокращенная история (одна строка на коммит)
git log --graph                # с графом веток (красиво!)
git log --oneline --graph      # сокращенная + граф
git diff                        # посмотреть изменения до add
git diff --staged              # посмотреть изменения в staging

Отмена изменений
git reset HEAD <файл>          # убрать файл из staging
git checkout -- <файл>         # откатить файл к последнему коммиту
git reset --soft HEAD~1        # отменить последний коммит (изменения сохранены)
git reset --hard HEAD~1        # отменить последний коммит (изменения удалены)
git reset --hard HEAD          # откатить всё к последнему коммиту
